# Himalaya Feb Sales Dashboard

An interactive Power BI dashboard created to analyze February sales performance, regional distribution, top product categories, and key sales metrics for Himalaya.

---

## Executive Summary and Key Insights

* Sales Overview: Analysis of monthly revenue, unit volume, and performance trends.
* Product Performance: Categorization of high-performing SKUs and revenue drivers.
* Regional Analysis: Sales distribution across different regions and key market territories.
* Visual Design: Custom formatting and visual components tailored for corporate reporting.

---

## Tools and Technologies Used

* Business Intelligence: Power BI Desktop
* Data Modeling: DAX measures, time-intelligence calculations, star schema modeling
* Data Transformation: Power Query

---

## How to View This Project

1. Download the `Himalaya Feb Sales Dash.pbix` file directly from this repository.
2. Open the file in Power BI Desktop to interact with the dashboard, data model, and DAX measures.
